# 8085 Microprocessor Simulator

## About the Project
The 8085 Microprocessor Simulator is a Java-based desktop application developed to demonstrate the working of the 8085 microprocessor. It provides a graphical interface to visualize CPU components and understand instruction execution through animation.

## Features
- Interactive GUI using Java Swing.
- Visualization of CPU registers and memory.
- Simulation of ALU operations.
- Display of flag register status.
- Execution of 8085 instructions.
- Animated representation of data flow and instruction execution.

## Technologies Used
- Java
- Java Swing & Java fx
- Object-Oriented Programming

## How to Run
1. Clone or download the repository.
2. Open the project in a Java IDE.
3. Locate the main Java class.
4. Run the application.
